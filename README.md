# 🎓 Student Registration Form

A simple **Student Registration Form** created using **HTML**. This project demonstrates the basics of HTML forms, tables, text input fields, dropdown menus, and image integration.

## 📌 Features

- 🏫 College logo display
- 👤 Student Name input field
- 🆔 Enrollment Number input field
- 📚 Course selection dropdown
- 📋 Simple and clean table-based layout
- 💻 Beginner-friendly HTML code

## 🛠️ Technologies Used

- HTML5

## 📂 Project Structure

```
Student-Registration-Form/
│── index.html
│── Logo.png
└── README.md
```

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Student-Registration-Form.git
   ```

2. Open the project folder.

3. Place the `Logo.png` image in the same folder as `index.html`.

4. Open `index.html` in any modern web browser.
